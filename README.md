# SpendWise – Personal Expense Tracker

## Project Description
SpendWise is a menu-driven Personal Expense Tracker developed using C programming.

It helps users record, view, update, delete and analyze their daily expenses while monitoring their monthly budget.

## Features
- Add expenses
- View expense history
- Calculate total spending
- Category-wise spending report
- Find highest spending category
- Check remaining budget
- Update monthly budget
- Update and delete expenses
- Permanent data storage using binary file handling

## Technologies Used
- C Programming
- Structures and Arrays
- Functions and Pointers
- File Handling
- Loops and Conditional Statements

## Categories
1. Food
2. Travel
3. Books
4. Entertainment
5. Others

## How to Run

Compile:
```bash
gcc main.c -o spendwise
```

Run:
```bash
./spendwise
```
